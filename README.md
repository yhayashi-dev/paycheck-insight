# paycheck-insight

2026年の会社員向けに、税金・社会保険料・手取り額を概算する Streamlit アプリです。

English UI is partially supported. Use the language selector at the top of the app to switch major labels to English.

## 公開アプリ

https://paycheck-insight-dfnvaodwxttypa7gtdouhj.streamlit.app

現在対応している都道府県は東京都・大阪府・神奈川県（横浜市想定）です。対象条件は、52歳・単身・扶養なし・会社員・協会けんぽ・給与収入のみ・賞与なし・年収を12か月均等支給に固定しています。

## 概要

年収を入力すると、以下を試算します。

画面で東京都・大阪府・神奈川県を選択できます。大阪府の住民税は大阪市、神奈川県の住民税は横浜市を居住地として概算します。

- 所得税
- 住民税
- 健康保険
- 介護保険
- 厚生年金
- 雇用保険
- 子ども・子育て支援金（本人・会社それぞれの合計に含む）
- 社会保険料の本人負担合計
- 会社負担分
- 年間手取り
- 月平均手取り
- 総人件費

また、年収200万円から1000万円まで100万円刻みの一覧も表示します。

## 使い方

依存関係をインストールします。

```bash
pip install -r requirements.txt
```

Streamlit アプリを起動します。

```bash
streamlit run app.py
```

テストを実行します。

```bash
PYTHONPATH=. pytest
```

## プロジェクト構成

```text
paycheck-insight/
  app.py
  requirements.txt
  data/
    rates_2026_osaka.json
    rates_2026_kanagawa.json
    rates_2026_tokyo.json
  src/
    calculators/
    services/
    ui/
  tests/
  docs/
```

主な役割は以下です。

- `app.py`: Streamlit 画面
- `data/rates_2026_tokyo.json`: 東京都の料率、控除額、地域依存項目、確認状況、出典情報
- `data/rates_2026_osaka.json`: 大阪府・大阪市の地域差分、確認状況、出典情報
- `data/rates_2026_kanagawa.json`: 神奈川県・横浜市の地域差分、確認状況、出典情報
- `src/calculators/`: 給与所得、所得税、住民税、社会保険料の計算
- `src/services/`: 料率読み込みとシミュレーション
- `src/ui/`: 表示用テーブル整形
- `tests/`: 計算ロジックとアプリ統合テスト
- `docs/`: 公式確認レポート

## 確認状況

2026-09-11のローカル修正版は、既存44件を維持し追加20件、計64件のテストに成功しています。公開反映は未実施です。確認状況と出典を画面内で確認できます。

| 区分 | provisional |
| --- | --- |
| 給与所得控除 | `false` |
| 所得税 | `false` |
| 住民税 | `false` |
| 社会保険料 | `true` |

所得税は復興特別所得税を加えた年調年税額の100円未満切捨てに修正。支援金は2026年度0.23%を労使折半し、給与天引きの本人分は50銭以下切捨て・50銭超切上げで個別に概算します。本人分は社会保険料控除にも反映します。会社だけが負担する従来の子ども・子育て拠出金0.36%とは別制度です。

社会保険料の全体フラグは概算条件が残るため `true` を維持します。料率の確認済み表示は、全勤務先の実際の控除額や全制度の網羅性を保証しません。

## 年額と端数処理の適用範囲

**表示額は2026年度料率の12か月換算です。2026年の実徴収額ではありません。** 支援金は2026年4月分（5月納付分）からですが、従来の年額モデルを維持しています。暦年内の月別料率変更・控除月の切替は計算していません。

支援金を個別に丸めた概算です。会社分は一人分の納付額を円未満切捨てした額から本人分を引いた参考配賦額で、事業所全員を合算した実際の請求・配賦とは異なることがあります。健康保険料との合算方法や労使の特約による差もあります。勤務先の給与計算との完全一致は確認できていません。

## 注意事項

- 本アプリは概算ツールです。実際の税額、保険料、手取り額を保証するものではありません。
- 現在対応している都道府県は東京都・大阪府・神奈川県（横浜市想定）です。大阪府の住民税は大阪市、神奈川県の住民税は横浜市を前提とします。
- 年齢・世帯条件は52歳・単身・扶養なし・協会けんぽ・給与収入のみ・賞与なしに固定しています。
- 健康保険料率と住民税設定は地域依存項目として管理しています。
- 住民税は前年所得課税のため、入力年収を前年も同じだったものとして概算しています。
- 年末調整の過不足精算、追加控除、扶養控除、配偶者控除、所得金額調整控除、賞与、自治体差、勤務先固有の扱いは対象外です。
- 社会保険料は標準報酬月額を年収の12か月均等支給から概算しています。
