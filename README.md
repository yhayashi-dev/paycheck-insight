# Paycheck Insight

会社員の税金・社会保険料・手取りを試算するStreamlitアプリです。第一版のローカル正本は確認済み21地域に対応しています。全国全自治体に対応したサービスではありません。

## 対応地域

東京23区、大阪市、横浜市、福岡市、千葉市、さいたま市、札幌市、仙台市、新潟市、広島市、高松市、金沢市、静岡市、京都市、神戸市、長野市、岡山市、熊本市、那覇市、松山市、盛岡市。

自治体と協会けんぽ支部を組み合わせたプリセットです。都道府県内すべての自治体を表すものではなく、住所から実際の加入保険支部を推定するものでもありません。

公式情報を基に計算しています。各地域の年度・支部・公式出典・根拠確認日は、画面の「確認状況と出典」と `data/period_settings.json` で確認できます。

## 試算の前提

- **12か月換算概算**：年収を12等分した給与に、指定月の保険料条件を12か月適用。実際の暦年・給与明細を再現するものではありません。
- 国内居住の給与所得者、52歳固定、単身・扶養なし、協会けんぽ、雇用保険は一般の事業。
- 所得税は2026年分の年末調整を想定（12月施行の改正を含む）。復興特別所得税を含みます。
- 住民税は2026年度・2025年所得。住所判定日は2026年1月1日です。
- 前年給与収入・前年社会保険料は当年と同額と仮定。実際の前年値や転居による違いは反映しません。
- 社会保険は2026年4月分の条件。年収÷12から標準報酬等級を推定します。実際の資格期間・報酬改定・保険者が異なる場合は差が出ます。
- 賞与設定・金額入力は画面上にありますが、**計算には未反映**です。賞与なし前提の試算として扱ってください。
- 子ども・子育て支援金は2026年4月分開始の条件を12か月換算し、本人・会社負担に含みます。暦年中の実徴収額とは異なります。
- その他所得、複数給与、扶養・配偶者等の追加控除、個人別の減免・勤務先固有の合算端数処理は対象外です。

表示項目は所得税、住民税、健康保険、介護保険、厚生年金、雇用保険、支援金、社会保険合計、手取り、会社負担、総人件費です。内訳の支援金を合計へ再加算しないでください。

English mode supports major labels; some official terms and source descriptions remain Japanese.

## ローカル起動・テスト

```sh
pip install -r requirements.txt
python3 -m streamlit run app.py
python3 -m pytest -q
```

公開リポジトリには本番計算・設定検証・UIのテストを収録します。全国化研究専用のテストと証拠資料はローカル保管で、公開リポジトリの実行には不要です。

## 設定・出典

- `data/period_settings.json`：制度設定の正本。所得税年、住民税年度、保険料適用月を独立管理。
- `data/rates_2026_*.json`：21地域の選択プリセット。
- `src/calculators/`、`src/services/`：計算・検証。`app.py`：画面。
- `tests/`：公式根拠を使った計算・境界・回帰・安全性テスト。
- `docs/`：過去の検証記録。古い文書の数値は当時の結果であり、現在の設定・テストを優先してください。

保存済み公式資料と出典URLの到達確認は別の検査です。HTTP到達成功だけで制度内容や年度の正しさを保証しません。古い監査文書・代表数値は当時の記録として保持し、現在値は最新設定と最終監査を参照してください。

## 全国化研究の引継ぎ

全国自治体masterとcandidate/review/completeness基盤は構築済みです。ただし全国全自治体verifiedではありません。

- 県差分：verified8県、needs_review39県。
- 8県内：252自治体candidateの実証。行政区68件は親市と重複計上しません。
- 市町村実証の新規verified0。candidateは公開選択肢・本番計算の対象外です。
研究用の原本、SHA、review履歴、provenance、checkpoint、全国自治体masterはローカルに保存し、公開リポジトリへ含めません。将来拡張可能ですが、全国全件verifiedは第一版完成条件にしません。
